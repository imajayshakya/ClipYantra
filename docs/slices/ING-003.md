## 5. Data model additions (from DATA-MODEL §2)

```sql
-- transcripts
CREATE TABLE transcripts (
    id              UUID PRIMARY KEY,
    source_id       UUID NOT NULL REFERENCES source_videos(id) ON DELETE CASCADE,
    workspace_id    UUID NOT NULL,
    media_asset_id  UUID NOT NULL REFERENCES media_assets(id) ON DELETE CASCADE,
    provider        TEXT NOT NULL,                     -- whisperx, deepgram, groq, openai, nvidia_nim
    model           TEXT NOT NULL,                     -- e.g. whisper-large-v3, nova-2
    language        TEXT NOT NULL,                     -- ISO 639-1 code
    full_text       TEXT NOT NULL,
    status          TEXT NOT NULL DEFAULT 'pending',   -- pending, completed, failed
    version         INT NOT NULL DEFAULT 1,
    validation_error JSONB,                            -- structured error if failed
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX ix_transcripts_source ON transcripts(source_id);
CREATE INDEX ix_transcripts_media_asset ON transcripts(media_asset_id);

-- transcript_segments
CREATE TABLE transcript_segments (
    id              UUID PRIMARY KEY,
    transcript_id   UUID NOT NULL REFERENCES transcripts(id) ON DELETE CASCADE,
    start_ms        BIGINT NOT NULL,
    end_ms          BIGINT NOT NULL,
    text            TEXT NOT NULL,
    speaker         TEXT,                              -- speaker label if diarization enabled
    confidence      NUMERIC(4,3),                      -- 0.000-1.000
    word_alignments JSONB,                             -- array of {word, start_ms, end_ms, confidence}
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX ix_transcript_segments_transcript ON transcript_segments(transcript_id);
CREATE INDEX ix_transcript_segments_timerange ON transcript_segments(start_ms, end_ms);
```

SourceVideos status adds: `transcribing`, `transcribed`, `transcription_failed`.

## 7. Transcription job pipeline

```
POST /transcribe
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ TranscriptionJob (Celery task)                              │
├─────────────────────────────────────────────────────────────┤
│ 1. Validate MediaAsset exists, status=validated             │
│ 2. Update source_videos.status = 'transcribing'             │
│ 3. Create Transcript record (status=pending, version=N+1)   │
│ 4. Extract audio via FFmpeg (WAV 16kHz mono) to temp        │
│ 5. If duration > 30 min: chunk with 30s overlap             │
│ 6. For each chunk:                                          │
│    a. Call ASR provider via capability registry             │
│    b. Validate response schema                              │
│    c. Map chunk-relative timestamps to absolute source ms   │
│ 7. Merge chunk results, deduplicate overlap text            │
│ 8. Persist Transcript + TranscriptSegment rows              │
│ 9. Update Transcript.status = 'completed'                   │
│ 10. Update source_videos.status = 'transcribed'             │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
On failure: source → 'transcription_failed', Transcript.status = 'failed',
            validation_error populated with structured error
```

## 8. Provider abstraction (per AI-PROVIDER-STRATEGY)

```python
@dataclass(frozen=True)
class TranscriptionRequest:
    audio_path: Path
    language: str | None          # None = auto-detect
    diarization: bool
    word_alignments: bool

@dataclass(frozen=True)
class TranscriptionResult:
    full_text: str
    language: str
    segments: list[SegmentResult]
    provider_metadata: dict       # raw response reference, usage, latency

@dataclass(frozen=True)
class SegmentResult:
    start_ms: int
    end_ms: int
    text: str
    speaker: str | None
    confidence: float
    word_alignments: list[WordAlignment] | None

@dataclass(frozen=True)
class WordAlignment:
    word: str
    start_ms: int
    end_ms: int
    confidence: float

class TranscriptionProvider(ABC):
    @property
    @abstractmethod
    def provider_name(self) -> str: ...

    @property
    @abstractmethod
    def model_id(self) -> str: ...

    @property
    @abstractmethod
    def supports_diarization(self) -> bool: ...

    @property
    @abstractmethod
    def supports_word_alignments(self) -> bool: ...

    @property
    @abstractmethod
    def supported_languages(self) -> set[str]: ...

    @abstractmethod
    async def transcribe(self, request: TranscriptionRequest) -> TranscriptionResult: ...

class CapabilityRegistry:
    def get_transcription_provider(
        self,
        hint: str | None,
        language: str | None,
        diarization: bool,
        word_alignments: bool
    ) -> TranscriptionProvider: ...
```

**Implemented providers (minimum):**
- `WhisperXProvider` — local, GPU-optional, supports diarization + word alignments
- `DeepgramProvider` — cloud, fast, supports diarization + word alignments
- `GroqProvider` — cloud, fast (Whisper), no diarization/word-align
- `OpenAIProvider` — cloud (Whisper), no diarization/word-align
- `NvidiaNimProvider` — self-hosted NIM, supports NVIDIA Canary/Parakeet

## 9. Audio extraction (FFmpeg)

```bash
# Extract 16kHz mono WAV for ASR
ffmpeg -i {input} -vn -acodec pcm_s16le -ar 16000 -ac 1 {output}.wav

# Chunk with overlap (30 min chunks, 30s overlap)
ffmpeg -i {input} -vn -acodec pcm_s16le -ar 16000 -ac 1 \
  -f segment -segment_time 1800 -segment_start_number 0 \
  -reset_timestamps 1 -strftime 1 "chunk_%03d.wav"
```

Overlap handling: re-transcribe last 30s of previous chunk, merge by timestamp deduplication.
