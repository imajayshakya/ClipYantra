**Goal:** Implement scene boundary detection and representative keyframe extraction for transcribed MediaAssets. Store scene metadata (start/end timestamps, keyframe asset references, scene labels) in the database to enable downstream candidate discovery and visual search.

**Out of scope:** Face detection/speaker tracking (ING-005), audio event signals (ING-005), gaming adaptive sampling (ING-005), candidate generation (PROC-002), any LLM-based scene understanding.

---

## 2. User value

After a video is transcribed, the system automatically detects scene boundaries and extracts representative keyframes. This enables:
- Visual navigation in Clip Studio timeline
- Candidate window proposals aligned to scene boundaries
- Representative thumbnails for video library and candidate cards
- Source maps for B-roll insertion and visual effects

---

## 3. Scope

### In scope
1. **SceneDetector service** — FFmpeg/FFprobe-based scene detection using `select='gt(scene,<threshold>)'` filter
2. **KeyframeExtractor service** — Extract representative frame (middle of scene or scene start) as JPEG/PNG
3. **Scene detection Celery task** — Async, restartable job with progress events
4. **API endpoints** — Trigger detection, get status, list scenes for a MediaAsset
5. **Database models** — Scene entity with start/end ms, keyframe asset FK, labels JSONB
6. **Alembic migration** — Create `scenes` table with indexes
7. **Storage integration** — Save keyframes via StorageAdapter (LocalFilesystem/S3)
8. **Unit + integration tests** — Cover detector, extractor, task, API, migration

### Out of scope
- Face detection, speaker tracking, face clustering
- Audio event detection (silence, laughter, speech turns)
- Gaming-specific adaptive sampling (dense/event-triggered)
- LLM-based scene classification or semantic labeling
- Candidate generation from scenes
- Visual search/embedding generation

## 5. API / Data Impact

### New API endpoints (under `/api/v1/sources/{media_asset_id}/scenes`)

| Method | Path | Purpose |
|---|---|---|
| POST | `/detect` | Trigger scene detection job (idempotent) |
| GET | `/detection` | Get detection job status/progress |
| POST | `/detect/retry` | Retry failed detection |
| GET | `/` | List scenes with pagination |
| GET | `/{scene_id}` | Get single scene detail |
| POST | `/{scene_id}/retry` | Re-extract keyframe for scene |

### Request/Response schemas

```python
# POST /detect request
class SceneDetectionRequest(BaseModel):
    threshold: float = Field(default=0.3, ge=0.1, le=1.0)  # scene change sensitivity
    min_scene_duration_ms: int = Field(default=1000, ge=500)  # minimum scene length
    extract_keyframes: bool = True
    keyframe_format: Literal["jpeg", "png"] = "jpeg"
    keyframe_quality: int = Field(default=80, ge=50, le=100)

# POST /detect response
class SceneDetectionResponse(BaseModel):
    job_id: str
    status: Literal["queued", "running"]
    idempotency_key: str

# GET /detection response
class SceneDetectionStatusResponse(BaseModel):
    job_id: str
    status: Literal["queued", "running", "succeeded", "failed", "cancelled"]
    progress: Optional[float] = None  # 0.0-1.0
    scenes_detected: int = 0
    error: Optional[str] = None

# GET / response (paginated)
class SceneListResponse(BaseModel):
    scenes: List[SceneResponse]
    total: int
    page: int
    page_size: int

class SceneResponse(BaseModel):
    scene_id: str
    media_asset_id: str
    start_ms: int
    end_ms: int
    keyframe_asset_id: Optional[str] = None
    keyframe_url: Optional[str] = None  # presigned, expires
    labels: Optional[Dict[str, Any]] = None  # JSONB: e.g., {"type": "dialogue", "confidence": 0.9}
    created_at: datetime
    updated_at: datetime
```

### Database changes

**New table: `scenes`**
```sql
CREATE TABLE scenes (
    scene_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    media_asset_id UUID NOT NULL REFERENCES media_assets(media_asset_id) ON DELETE CASCADE,
    start_ms INTEGER NOT NULL,
    end_ms INTEGER NOT NULL,
    keyframe_asset_id UUID REFERENCES media_assets(media_asset_id) ON DELETE SET NULL,
    labels JSONB DEFAULT '{}',
    detection_job_id UUID REFERENCES processing_jobs(job_id) ON DELETE SET NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT valid_time_range CHECK (end_ms > start_ms),
    CONSTRAINT within_source_duration CHECK (end_ms <= (SELECT duration_ms FROM source_videos WHERE source_id = (SELECT source_id FROM media_assets WHERE media_asset_id = scenes.media_asset_id)))
);

CREATE INDEX idx_scenes_media_asset ON scenes(media_asset_id);
CREATE INDEX idx_scenes_time_range ON scenes(media_asset_id, start_ms, end_ms);
CREATE INDEX idx_scenes_detection_job ON scenes(detection_job_id);
```

## 8. Security / Rights Checks

- [ ] Scene detection only runs on MediaAssets with `rights_state = 'declared'` and user owns workspace
- [ ] Keyframe presigned URLs expire (default 1 hour, configurable)
- [ ] No media bytes exposed in API responses (only storage keys/presigned URLs)
- [ ] FFmpeg subprocess runs with resource limits (timeout, memory)
- [ ] Input validation: threshold in [0.1, 1.0], min_duration >= 500ms
- [ ] Idempotency prevents duplicate processing charges

---

## 9. Rollback Strategy

| Failure Point | Rollback Action |
|---|---|
| Migration fails | `alembic downgrade -1` — drops `scenes` table |
| SceneDetector crashes | Job marked failed, no partial scenes committed (transaction per scene batch) |
| Keyframe extraction fails | Scene created without keyframe; retry endpoint available |
| StorageAdapter fails | Job failed, error event emitted; manual retry via API |
| Celery worker dies mid-job | Job lease expires, another worker picks up (idempotent by params hash) |
