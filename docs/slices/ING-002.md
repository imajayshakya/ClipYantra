## 5. Data model additions (from DATA-MODEL §3.2)

```sql
-- media_assets
CREATE TABLE media_assets (
    id              UUID PRIMARY KEY,
    source_id       UUID NOT NULL REFERENCES source_videos(id) ON DELETE CASCADE,
    workspace_id    UUID NOT NULL,
    storage_key     TEXT NOT NULL,
    checksum        CHAR(64) NOT NULL,                 -- SHA-256 hex
    container       TEXT NOT NULL,                     -- mp4, mkv, webm
    video_codec     TEXT NOT NULL,                     -- h264, hevc, vp9
    audio_codec     TEXT,                              -- aac, opus, mp3
    duration_ms     BIGINT NOT NULL,
    width           INT NOT NULL,
    height          INT NOT NULL,
    bitrate         BIGINT,                            -- bits/sec
    fps             NUMERIC(6,3),                      -- e.g. 29.97
    audio_channels  INT,
    sample_rate     INT,
    validation_status TEXT NOT NULL DEFAULT 'pending', -- pending, validated, failed
    validation_error JSONB,                            -- structured error if failed
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
CREATE INDEX ix_media_assets_source ON media_assets(source_id);
CREATE UNIQUE INDEX uq_media_assets_source ON media_assets(source_id);
```

## 7. Storage adapter contract (CONTRACT-FREEZE §12)

```python
class StorageAdapter(ABC):
    @abstractmethod
    def store_original(self, key: str, stream: BinaryIO, content_length: int) -> str:
        """Store stream, return final key. Must be atomic."""
    
    @abstractmethod
    def read_original(self, key: str) -> BinaryIO:
        """Open readable stream for key."""
    
    @abstractmethod
    def delete(self, key: str) -> bool:
        """Delete key. Return True if existed."""
    
    @abstractmethod
    def exists(self, key: str) -> bool:
        """Check existence."""
    
    @abstractmethod
    def presign_upload(self, key: str, ttl_seconds: int = 3600) -> PresignedUpload:
        """Return {upload_url, key, expires_at} for direct client upload."""
    
    @abstractmethod
    def presign_download(self, key: str, ttl_seconds: int = 3600) -> str:
        """Return signed GET URL."""

@dataclass(frozen=True)
class PresignedUpload:
    upload_url: str
    key: str
    expires_at: datetime
```

**LocalFilesystemAdapter** — stores under `settings.media_root / key`. Presign returns `file://` URL (dev only).

**S3Adapter** — uses boto3, presigns real S3 URLs. Enabled via `settings.storage_backend = "s3"`.

## 8. FFprobe validation service contract

```python
@dataclass(frozen=True)
class MediaMetadata:
    container: str
    video_codec: str
    audio_codec: str | None
    duration_ms: int
    width: int
    height: int
    bitrate: int | None
    fps: float | None
    audio_channels: int | None
    sample_rate: int | None

class ValidationError(Exception):
    def __init__(self, code: str, message: str, details: dict | None = None):
        self.code = code
        self.message = message
        self.details = details or {}

class FFprobeValidator:
    # Supported per MEDIA-PIPELINE §2.1
    SUPPORTED_CONTAINERS = {"mp4", "mov", "mkv", "webm", "mp3", "wav", "m4a"}
    SUPPORTED_VIDEO_CODECS = {"h264", "hevc", "vp9", "av1"}
    SUPPORTED_AUDIO_CODECS = {"aac", "opus", "mp3", "pcm_s16le", "flac"}
    MAX_DURATION_MS = 2 * 60 * 60 * 1000  # 2 hours

    def validate(self, file_path: Path) -> MediaMetadata:
        """Run ffprobe, parse JSON, validate, return metadata or raise ValidationError."""
```

Validation error codes:
- `UNSUPPORTED_CONTAINER`
- `UNSUPPORTED_VIDEO_CODEC`
- `UNSUPPORTED_AUDIO_CODEC`
- `DURATION_EXCEEDED`
- `CORRUPT_MEDIA`
- `NO_VIDEO_STREAM`
- `NO_AUDIO_STREAM` (warning only)

## 9. Job integration

Validation runs as a **background job** (Celery task) so `/complete-upload` returns 202 immediately.

Job stages: `validating` (FFprobe) → `storing` (copy to canonical key if uploaded to temp) → `persisting` (write MediaAsset) → `succeeded`.

On failure: source → `rejected` with `validation_error`; job → `failed`.
